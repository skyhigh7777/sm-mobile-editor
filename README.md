# 譜面エディタ（SM Mobile Editor）

外出先の Android（Chrome）から、Etterna / StepMania の `.sm` 譜面（4 キー / dance-single）を編集するための簡易エディタです。ホーム画面に追加して、オフラインでも使えます。

公開ページ: https://skyhigh7777.github.io/sm-mobile-editor/

BPM・オフセット・拍子は、家の ArrowVortex で合わせた `.sm` を読み込む前提です。このアプリではタイミングは変えず、ノーツの配置だけを行います。

## できること

- `.sm` と音源（mp3 / ogg など）を端末から読み込む
- BPM とオフセットを手入力して、新規譜面を作る
- dance-single の難易度を選ぶ / 追加する
- 縦スクロールの 4 列グリッドに、タップでノートを置く・消す
- LN（開始を置いてから終わりを置く）
- スナップ: 4 / 8 / 12 / 16 / 24 / 32 / 48 / 64
- 小節線・拍線、DivideByZero / ArrowVortex 風のクォンタイズ色（4 分赤、8 分青、12 分緑、16 分黄…）
- Web Audio で再生。レセプターに合わせてスクロール。速度変更、ノートのアシスト音
- 取り消し / やり直し。再読み込みしても作業が消えないよう自動保存（IndexedDB）
- 編集したノーツを含む `.sm` を書き出す（他のヘッダや、触っていない難易度はそのまま）

## ホーム画面に追加する（Android Chrome）

1. Chrome で https://skyhigh7777.github.io/sm-mobile-editor/ を開く
2. 右上の「⋮」メニューを開く
3. 「ホーム画面に追加」または「アプリをインストール」を選ぶ
4. 追加する

初回はネットが必要です。一度開けば、以降はオフラインでもエディタ自体は起動します。音源と `.sm` は端末内に保存されます。

## 使い方の流れ

1. 「譜面」で `.sm` を開く（または「新規」で BPM とオフセットを入れて作る）
2. 「音源」で ogg / mp3 を開く（プレビュー用。書き出しには必須ではない）
3. 編集したい難易度を選ぶ
4. グリッドをタップしてノーツを置く。LN モードでは、同じ列をもう一度タップすると終わりになる
5. 「書き出す」で `.sm` を保存し、家に帰ってから ArrowVortex や Etterna に戻す

## 今はできないこと・注意

- タイミング（BPM / オフセット / 拍子 / stop）の編集はしない
- mine（地雷）や roll、fake を新しく置く UI はない（ファイルに入っていれば、書き出し時に残る）
- dance-single（4 列）以外は編集できない
- `.ssc` やキーサウンド、warp には未対応
- 再生プレビューの音ズレは端末によって出る。設定の「レイテンシ補正」で合わせられる（目安）。モバイル Chrome では数十 ms 程度ずれることがある
- ブラウザがストレージを回収すると、自動保存が消えることがある。書き出して控えを残すこと
- 家の PC とは自動では同期しない。書き出したファイルを自分で移す

## 開発

静的サイトです。バックエンドはありません。

```bash
# ローカルで開く例
python3 -m http.server 8080 --directory .

# パース / 書き出しのテスト
npm test
```

未編集の `.sm` は、書き出しても元のテキストと一致します。編集した難易度だけ、必要な最小解像度（4 / 8 / 12 / 16 / 24 / 32 / 48 / 64 / 192）で書き直します。
